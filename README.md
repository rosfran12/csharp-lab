# C# Lab — Unity & Game Audio

Aplicación web estática para estudiar tres rutas conectadas: C# general, C# para Unity y Game Audio.

## Uso

Abrí `index.html` en cualquier navegador. No requiere servidor ni instalar dependencias.

## Funciones

- Curso guiado y práctica libre.
- 12 ejercicios con corrección y explicaciones.
- Progreso independiente por ruta, con conceptos compartidos.
- Guardado en localStorage; exportación e importación JSON para trasladar el progreso entre dispositivos.
- Diseño adaptable a celular.

## Publicación

Subí `index.html` a un repositorio GitHub. En Cloudflare Pages, elegí ese repositorio, framework `None`, comando de compilación vacío y directorio de salida `/`. También puede publicarse como sitio estático en Vercel o GitHub Pages.

## Limitaciones

Las respuestas son de opción múltiple; los fragmentos C# son ilustrativos y no se compilan ni ejecutan. La app no sincroniza el progreso automáticamente entre dispositivos. La integración de Wwise es conceptual.
